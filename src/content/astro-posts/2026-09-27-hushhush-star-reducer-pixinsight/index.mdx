I've added a star reducer tool, HushHush, to the apeia astro tooling suite. I know, this already exists elsewhere, but I wasn't happy with the usability and wanted it to be more one-clicky.
I also added a few other tweaks that I find useful at the processing stage where I usually start to de-emphasize the stars.

The tool is most useful for wide-field shots, where the number of stars starts to get a bit out of hand. It can be used even when no star reduction is needed -
namely for star saturation and final contrast enhancement.

It works with both linear and stretched images.

### How it works
The tool separates the stars from the background object using StarXTerminator and processes each part separately. If you don't have StarXTerminator, you have to separate them by other means.
HushHush should then be opened with the starless image, and the stars image must be selected manually.

Just a note: the star selection box only lists images with the same resolution as the currently loaded one. I tripped over this myself - I couldn't find my stars image
and started looking for a bug, only to eventually find that it had a different resolution because I had extracted it from a differently cropped version.

#### Functions
- Automatic star extraction
- Optional manual star selection
- Star manipulation
  - Strength
  - Saturation
- Background object manipulation
  - Contrast

### Installation
1. Add the link below to PixInsight's script repositories via RESOURCES -> Updates -> Manage Repositories. The link must end with a trailing `/` character, otherwise PixInsight will not recognize it.
2. Click RESOURCES -> Updates -> Check for Updates. 
3. Restart PixInsight.
4. You will find it here: SCRIPT -> apeia -> HaloHalo

```
https://apeia.eu/astro-tools/halohalo/
```
