There are basically two methods for green tint suppression in our images. One is a relatively laborious manual hue manipulation, the other is the mighty SCNR.
The problem with SCNR is that you risk losing data in the green channel and losing the distinction between different areas that are visible in the untreated image.

<PostFigure src={wizardGreenTint} alt="Greenish Wizard" caption="Greenish Wizard with clearly discernible reddish nebulosity." />
<PostFigure src={wizardScnr} alt="SCNR" caption="SCNR eats the distinction between reddish and greenish parts." />

There is a better way. The idea is to plot all pixels onto a hue wheel and continuously shift the greenish pixels away from the green area. It is quite intuitive when you see it. 
It is basically a one-click operation. When the tool is opened, it automatically fits the settings to the actual image. The one click is the apply button itself.

<PostFigure src={wizardTintCorrected} alt="Corrected Wizard in the Tool" caption="Corrected Wizard in the Tool" />

I know, it's only a small helper and one can achieve the same result by other means too. But it is much more controllable and you can see what's really happening. 
SCNR squashes the colours towards the oranges, GreenGreen always keeps the separation.

I generalised the tool, so it can be used for every continuous hue shift of any colour band on the wheel. Just set the white pie where you want it and set its colour band width.
Then you can adjust the colour shift by turning the yellow target pie. 

For example, you can shift blues to a more desirable hue.

By checking "Work on the starless image" you omit the stars from the process. StarXTerminator must be installed for it to be working.

### Installation
It is part of the apeia/HaloHalo tool suite (see the flagship star halo removal tool, [HaloHalo](/astro/blog/2026-09-10-halohalo-star-removal-pixinsight/)).

1. Add the link below to PixInsight's script repositories via RESOURCES -> Updates -> Manage Repositories. The link must end with a trailing `/` character, otherwise PixInsight will not recognize it.
2. Click RESOURCES -> Updates -> Check for Updates. 
3. Restart PixInsight.
4. You will find it here: SCRIPT -> apeia -> HaloHalo
