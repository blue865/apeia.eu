I have always struggled with star halos and have tried lots of workflows one can find on YouTube or on the internet in general.
Tedious the work was, with limited and unsatisfactory outcomes. The little HaloHalo tool is my attempt to squash these
nasty gremlins of stray optics I've learnt to hate.

Now the removal is mostly a matter of a few clicks. The best results can be achieved with linear images but the tool works with stretched ones as well.


### Installation
1. Add the link below to PixInsight's script repositories via RESOURCES -> Updates -> Manage Repositories. The link must end with a trailing `/` character, otherwise PixInsight will not recognize it.
2. Click RESOURCES -> Updates -> Check for Updates. Unfortunately I'm not a registered PixInsight developer yet, so PixInsight will ask whether you really want to install the script. Click yes.
3. Restart PixInsight.

```
https://apeia.eu/astro-tools/halohalo/

```
